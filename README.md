## 📖 Overview

**Sense Data** is a web application designed for personal expense management and financial tracking. The core objective of this project is to provide a seamless user experience for logging, organizing, and analyzing daily expenses through a clean and intuitive interface. 

The application architecture relies on modular components, utilizing BEM methodology for styling and a structured API integration for data handling.

* **Authentication System:** A functional email and password login mechanism featuring real-time validation, dynamic error feedback, and pre-configured hardcoded users for development and testing environments.
* **Comprehensive Expense Management:** Full CRUD (Create, Read, Update, Delete) capabilities allowing the logged-in user to easily manage their financial records.
* **Detailed Logging:** Each transaction captures essential data points, including Value, Date, Description, and Category.
* **Advanced Data Organization:** Built-in sorting and filtering mechanisms enabling users to efficiently find specific expenses based on categories or monetary values.

## 📦 Install and Use

**Prerequisites:** Node.js (v22.x) or higher installed.

1. Clone the repository:
```bash
git clone https://github.com/Epiled/sense-data.git
cd sense-data
```

2. Install the dependencies:
```bash
npm install
```

3. Run the development server:
```bash
npm run serve
```

4. Run the development environment (Build + Watch + Server):
```bash
npm run dev
```

## 📂 File Structure

Below is the project architecture. All development should be done inside the src/ folder.

```
sense-data/
├── data/                    # Static JSON datasets, mock responses, or local data
├── design/                  # Wireframes, videos and assets for documentation
├── pages/                   # Additional HTML views, templates, or secondary routes
├── src/                     # Main source code (Development)
│   ├── api/                 # Fetch handlers, external requests, and data integration logic
│   ├── assets/              # Original images and icons
│   ├── css/                 # Styles following architecture BEM
│   └── js/                  # UI logic and PWA registration
├── index.html               # Base semantic structure and main markup
└── package.json             # Project dependencies and npm scripts
```
